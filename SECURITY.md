# Security Policy

## Supported versions

Only the latest release is supported. Please update to it before reporting a problem.

## What the app exposes

The app runs on your home network. It advertises a Zwift-compatible device over mDNS and listens on a TCP port so Zwift can connect. It is meant for a trusted local network, not the internet.

## Reporting a vulnerability

Please open an issue on the [Issues page](https://github.com/VoltageSolutions/GameControllerForZwift/issues).

If you think the details should not be public, open an issue that says so without including the details, and I will follow up with you.
